# Портфолио-резюме графического дизайнера Даши (Windows 95 Desktop Edition)

Одностраничный интерактивный веб-сайт — портфолио и резюме графического дизайнера, фотографа и иллюстратора, выполненный в эстетике операционной системы **Windows 95 / Retro'98**.

## Стек технологий и архитектура
* **HTML5** (семантическая верстка: `header`, `main`, `section`, `article`, `aside`, `footer`).
* **CSS3 (Mobile First)**: модульная структура таблиц стилей (`reset.css`, `variables.css`, `base.css`, `win95-components.css`, `desktop-layout.css`). Базовый слой оптимизирован под мобильные экраны (`320px+`), десктопная раскладка подключается через `@media (min-width: 768px)` и `@media (min-width: 1024px)`.
* **JavaScript (ES6 Modules)**: чистая компонентная архитектура без глобальных переменных и спагетти-кода.

## Реализованный JavaScript-функционал
1. **Оконный менеджер (`js/modules/windowManager.js`)**: открытие, закрытие, сворачивание в панель задач, разворачивание на весь экран и динамический пересчет `z-index` активного окна.
2. **Drag-and-Drop (`js/modules/dragAndDrop.js`)**: свободное перетаскивание окон мышью за заголовок на десктопных экранах с ограничением вылета за края вьюпорта.
3. **Динамический рендеринг и фильтрация (`js/modules/renderDesktop.js`)**: генерация 12 кейсов портфолио из массива данных и фильтрация ярлыков по направлениям («Брендинг & Web», «Полиграфия & Афиши», «SMM & Контент», «2D-Игры & Арт»).
4. **Системный трей и интерактив (`js/modules/systemTray.js`)**: часы реального времени, меню «Пуск», переключение обоев рабочего стола и интерактивная форма обратной связи.

## Отчет об использовании AI-помощника (Обязательное требование)
* **Инструмент:** Google Gemini
* **Этапы использования:** Проектирование файловой архитектуры ES6-модулей, создание CSS-токенов для 3D-рамок Windows 95 и структурирование текстов из PDF-портфолио в формат JSON/JS-объектов.
* **Время выполнения с AI:** ~2.5 часа.
* **Существенный запрос (промпт):**
  > «Спроектируй модульную файловую структуру и код одностраничного сайта-портфолио для графического дизайнера в стиле рабочего стола Windows 95. Иконки проектов должны располагаться вокруг центрального портрета на десктопе и перестраиваться в сетку по принципу Mobile First на смартфонах. Реализуй менеджер окон и фильтрацию на чистом JavaScript (ES6 Modules) для публикации на GitHub Pages».
* **Результат проверки и самостоятельные исправления:**
  1. Проверена работа Drag-and-Drop на мобильных разрешениях в Chrome DevTools: перетаскивание отключено на экранах `< 1024px`, чтобы не блокировать нативный тач-скролл страницы.
  2. Увеличены размеры системных кнопок управления окнами (`[ _ ] [ □ ] [ X ]`) в мобильной версии для удобного нажатия пальцем.
  3. Добавлены локальные скриншоты проектов Даши в папку `assets/img/` и проверены относительные пути `./` для корректной работы на GitHub Pages.
